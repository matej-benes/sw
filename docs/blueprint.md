# **App Name**: ŠkolaWeb

## Core Features:

- Authentication: Firebase Authentication for user login with email/password.
- Role-based Redirection: Redirect users to appropriate dashboards based on their role (učitel, rodic, ziak).
- Teacher Dashboard: Dashboard for teachers to manage grades and communicate with students/parents.
- Parent Dashboard: Dashboard for parents to view their child's grades and communicate with teachers.
- Student Dashboard: Dashboard for students to view their grades and access resources.
- Grade Management: Teachers can input and manage student grades. Grades will be stored in Firestore.
- Communication Tool: Secure messaging system between teachers, parents, and students.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a trustworthy and educational feel.
- Background color: Very light blue (#E8EAF6), almost white, providing a clean and calm backdrop.
- Accent color: A bright, contrasting orange (#FF9800) to draw attention to interactive elements and important information.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text, ensuring a modern and readable interface.
- Use clear, consistent icons from a library like Material Icons, tailored to educational contexts.
- Clean and intuitive layout with clear navigation for each role-based dashboard.
- Subtle transitions and animations to enhance user experience.
